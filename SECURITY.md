# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues,
pull requests, or discussions.

Report privately on GitHub: open the affected repository's **Security**
tab and choose **Report a vulnerability**. For issues in the Meshive
platform itself, report through the
[meshive-python](https://github.com/meshive/meshive-python/security/advisories/new)
repository.

## What to include

- The affected repository, package, or image, and its version or commit
- What an attacker could do (impact)
- Steps to reproduce, with any secrets removed

## Scope

Public repositories in the meshive organization, the `meshive` package on
PyPI, and the `meshive/meshive-mcp` image on Docker Hub.
Fixes ship in the latest release.
